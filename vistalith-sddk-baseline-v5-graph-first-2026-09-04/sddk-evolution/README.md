# SDDK Evolution Candidates Discovered Through Vistalith

This directory is **not an executable roadmap** and does not change SDDK's current
canonical H0→H12 sequence.

It records semantic capabilities that Vistalith may prove valuable enough to
propose upstream into SDDK.

SDDK's existing canonical roadmap/execution spine remains authority.

## Admission principle

A feature moves from Vistalith into an SDDK proposal only when it serves SDDK
without requiring Vistalith, a GUI or an LLM.
