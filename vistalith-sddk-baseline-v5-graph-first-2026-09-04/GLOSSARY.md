# Glossary

**Semantic Subject** — stable identity for something meaningful in software:
project, requirement, decision, component, symbol, test, workflow, agent, evidence,
artifact, visual idea, etc.

**Semantic World Graph (SWG)** — Vistalith's typed graph combining authoritative,
derived, advisory and ephemeral subjects/relations.

**Authority Class** — `authoritative`, `derived`, `advisory`, `ephemeral`.

**Provenance** — where a subject/relation/assertion came from and which revision
supports it.

**Reactive Behavior** — deterministic/advisory function triggered by events or
graph patterns that proposes changes or derived projections.

**Relation Behavior** — behavior associated with a semantic relationship rather
than one endpoint.

**Graph Patch** — proposed mutation to Vistalith-owned graph state with a base
revision and optimistic concurrency.

**Visual Intent** — typed semantic intention derived from visual interaction.

**Semantic Change Proposal** — renderer-independent proposal that may later become
SDDK-governed work.

**Lens** — a projection of semantic subjects: C4, workflow, decision, evidence,
impact, trace, timeline, code, etc.

**Frame** — bounded goal/context/budget/policy view for an agentic activity.

**Pull-up** — moving a proven generic semantic capability from Vistalith into an
SDDK proposal while leaving UI/LLM-specific mechanics in Vistalith.
