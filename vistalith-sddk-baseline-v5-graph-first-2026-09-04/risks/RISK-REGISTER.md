# Risk Register

| Risk | Mitigation |
|---|---|
| Vistalith becomes a Cursor clone | visual/graph UAT precedes deep editor |
| Graph becomes second SDDK authority | authority classes + direct SDDK truth + rebuild tests |
| ActiveGraph inspiration creates second workflow engine | reactive layer limited; governed work enters SDDK |
| SurrealDB locks domain to query engine | repository adapter + domain tests + spike |
| Event sourcing becomes excessive complexity | only Vistalith-owned durable semantic state; measure replay value |
| Huge graph freezes UI | bounded views, server-side slices, workers, pagination |
| Relation behaviors create unpredictable cascades | budgets, determinism class, trace, bounded drains |
| LLM assertions become "facts" | advisory class + provenance/confidence |
| Context graph explodes token budget | SemanticContextView + lazy expansion |
| Visual drag causes effects | VisualIntent lifecycle |
| SDDK semantics duplicated | direct core dependency + ownership fitness tests |
| Pull-up pollutes SDDK | strict admission filter and canonical roadmap governance |
| Too many crates early | architecture-emergence ratchet |
| Provider/MCP security | secrets backend-only, unified tool permissions, gateway composition |
