# Fork, Diff and Time Travel

## Exploration fork

Fork Vistalith-owned semantic/agentic state at graph/event revision R.

Change:
- assumption;
- model;
- agent strategy;
- architecture candidate;
- context view;
- tool availability.

Run bounded exploration.

Compare to parent:
- added/removed subjects;
- added/removed/changed relations;
- changed confidence;
- cost/latency;
- evidence differences;
- decisions proposed;
- impacted SDDK subjects.

## SDDK interaction

An exploration branch is advisory.

Promotion into SDDK is explicit and governed.

## Time travel

Users can render:
- graph at event/revision;
- architecture at two revisions;
- decision branches;
- workflow history;
- agent trace;
- evidence freshness history.

The UI animates history; the semantic engine supplies revisioned projections.
