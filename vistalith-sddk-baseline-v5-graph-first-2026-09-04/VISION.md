# Vision

## Commercial name
**Vistalith**

## Category
**Visual Agentic Engineering Environment**

## Product line
**See the system. Shape the system.**

## Ambition

Vistalith should combine the operational strengths of modern coding agents
(chat, providers, tools, subagents, MCP, permissions, traces) with something
those products still treat weakly: **software as a manipulable semantic world**.

The user can:

- converse with the system;
- mention semantic software subjects rather than only files;
- inspect architecture and runtime/workflow relationships;
- sketch ideas before formalizing them;
- ask several agents to explore alternatives;
- compare branches visually;
- promote an idea into a typed engineering proposal;
- preview impact;
- create governed SDDK work;
- observe execution and evidence;
- replay why the system reached the current state.

## Signature experience

```text
"@PaymentService, explore three ways to remove this coupling"
       ↓
three agent investigations
       ↓
three visual architecture branches
       ↓
semantic comparison
       ↓
select one
       ↓
VisualIntent
       ↓
impact preview
       ↓
SDDK WorkItem / decision / workflow
       ↓
live agent/workflow visualization
       ↓
code + tests + evidence
       ↓
updated architecture + Decision Memory
```
