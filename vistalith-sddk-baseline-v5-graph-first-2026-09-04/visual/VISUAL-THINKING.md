# Visual Thinking

## Goal
Make sketching, exploring and comparing first-class engineering activities.

## Free-form primitives
- Note;
- Question;
- Hypothesis;
- Option;
- Group;
- Sketch;
- Arrow/relationship;
- Image/reference;
- Agent proposal.

These begin as Vistalith-owned advisory semantic subjects.

## Progressive formalization

```text
free sketch
 → semantic annotation
 → candidate
 → VisualIntent
 → SemanticChangeProposal
 → impact preview
 → SDDK-governed work/decision
```

## Canvas
Use a `CanvasPort`; Excalidraw remains the preferred open-source initial adapter.

Never store Excalidraw IDs as canonical semantic identity.
