# UAT Studio

Use SDDK UAT semantics directly when the scenario is governed by SDDK.

Vistalith provides:
- guided wizard;
- instructions;
- checklists;
- evidence capture;
- screenshot/file attachment;
- pass/fail/block;
- defect creation;
- retest;
- signoff;
- graph traceability to requirement/work item/decision.

The GUI never defines a parallel UAT lifecycle.
