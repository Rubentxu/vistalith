# Workflow and Agent Visualization

## Renderer
React Flow + ELK initial adapter.

## Workflow
Project direct SDDK workflow/run state:
- sequence;
- conditional;
- parallel;
- gates;
- approval;
- status;
- evidence links.

## Agents
Overlay Vistalith/SDDK agent activity:
- delegation;
- model;
- tool use;
- current subject;
- status;
- contribution;
- cost/latency;
- dissent/conflict.

## No second workflow model
The graph visualizes SDDK workflow semantics rather than inventing an independent
execution DAG authority.
